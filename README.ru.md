ShareW это программа для скриншотов и разметки под Wayland в духе ShareX. Снимает область, окно или весь экран, даёт нарисовать поверх и отправляет результат куда нужно. Работает на любом композиторе и оконном менеджере: Sway, Hyprland, river, niri, KDE, GNOME и других.

> **Статус: планирование.** Пока в репозитории только лицензия и этот документ. Всё ниже описывает задуманный дизайн, а не готовые функции.

## Планируемые возможности

**Захват**

- Область, окно, весь экран, отдельный монитор
- Таймер задержки и «повторить прошлую область»
- Выбор области по замороженному кадру с лупой и точными маркерами
- Запись экрана (GIF / WebM) после того, как скриншоты станут стабильными

**Редактор**

- Карандаш, маркер, линия, стрелка, прямоугольник, эллипс
- Текст с выбором шрифта, размера, цвета и обводки
- Нумерованные маркеры шагов
- Размытие, пикселизация и подсветка области
- Пипетка, обрезка, отмена / повтор

**После съёмки**

- Копирование в буфер обмена (совместимо с `wl-clipboard`)
- Сохранение в папку по шаблону имени файла
- Загрузка на свои HTTP-эндпоинты, ссылка копируется в буфер
- Иконка в трее и уведомление с быстрыми действиями
- История последних снимков

**Интеграция**

- Обычное приложение с CLI: `shareW region`, `shareW screen`, `shareW window`
- Команды привязываются к клавишам в конфиге композитора, глобальные хоткеи самой ShareW не нужны
- Без привязки к конкретному окружению рабочего стола

## Как это будет работать на Wayland

Wayland намеренно не даёт клиентам читать экран и чужие окна, поэтому ShareW использует стандартные способы попросить об этом композитор:

| Способ | Когда используется |
| --- | --- |
| `xdg-desktop-portal` Screenshot / ScreenCast | GNOME, KDE и другие композиторы с portal-бэкендом |
| `ext-image-copy-capture-v1` / `wlr-screencopy-unstable-v1` | Композиторы на wlroots и другие с поддержкой протокола |
| `wlr-layer-shell` | Оверлей для выбора области там, где он поддерживается |

Бэкенд выбирается автоматически, его можно задать в конфиге. Если композитор не поддерживает ни один из способов, снимать на нём нельзя. Это ограничение Wayland, а не то, что стоит обходить.

## Технически

- C++20, Qt 6 (Widgets) для интерфейса и редактора, сборка через CMake
- Бэкенды захвата отделены от UI и скрыты за одним интерфейсом, новый бэкенд не трогает редактор
- Редактор хранит аннотации как объекты до экспорта, поэтому их можно править, а отмена дешёвая
- Настройки лежат в `~/.config/shareW/config.ini`

## Сборка

Пока собирать нечего. Когда появится код, шаги будут такими:

```
cmake -S . -B build
cmake --build build -j"$(nproc)"
```

Ожидаемые зависимости: компилятор с C++20, CMake 3.20+, Qt 6 (Base, Widgets), `wayland` и `wayland-protocols`.

## План

1. Захват экрана и области на композиторах wlroots
2. Portal-бэкенд для GNOME и KDE
3. Редактор: карандаш, фигуры, стрелки, текст
4. Размытие / пикселизация, маркеры шагов, буфер обмена и сохранение
5. Загрузка на серверы, история, трей
6. Запись экрана
